# 1. Objetivo de la etapa final

La investigación comenzó buscando canales del nicho que pudieran estar
monetizando.

Terminamos descubriendo algo más importante:

> **La ventaja competitiva no está en encontrar otra keyword de
> "Christian Jazz". Está en construir una identidad de contenido
> repetible y aprender qué combinaciones producen outliers para Alma &
> Vinilo.**

La evidencia actual confirma que varios canales están convergiendo en:

``` text
Christian Jazz
+
Coffee
+
Morning
+
Prayer
+
Study / Work
+
Bible / Scripture
```

Prayer & Jazz, Manna Jazz, Heaven Jazz Café, Morning Mercy Jazz y otros
utilizan variantes muy cercanas.

Por lo tanto, **SEO genérico no debe ser el núcleo de la estrategia.**

# 19. Packaging definitivo

La UI NO debe mostrar:

``` text
CONCEPTO VISUAL
BRIEF VISUAL
PROMPT VISUAL
```

como tres outputs equivalentes.

Debe mostrar:

``` text
TITLE
THUMBNAIL TEXT
THUMBNAIL PROMPT
DESCRIPTION
TAGS
```

El prompt visual es un **artefacto para el generador de imágenes**.

El texto de thumbnail es el **texto que eventualmente aparece sobre la
imagen**.

El título es el **texto que aparece debajo/arriba del video en
YouTube**.

# 25. Outlier Detection

# 26. Learning confidence

``` text

→ strong pattern
```

# 28. Recomendaciones automáticas

El Learning Engine debe poder generar:

``` text
REPEAT
EXPAND
TEST
RETIRE
```

### REPEAT

La combinación funciona consistentemente.

### EXPAND

Funciona y puede probarse en otra Scripture o momento.

### TEST

Hay señal pero falta evidencia.

### RETIRE

Rendimiento bajo después de varios intentos comparables.
