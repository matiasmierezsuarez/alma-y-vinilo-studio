# Data Model

The canonical entities are defined in
`ALMAYVINILO_STUDIO_2_FINAL_SPEC.md` section 37 and the TypeScript
definitions throughout sections 4, 6, 8, 17, 19.

Minimum relational entities: users, workspaces, content_dna, scriptures,
series, volumes, tracks, lyrics_versions, music_generations,
visual_references, visual_assets, packaging_versions, review_items,
publication_snapshots, analytics_snapshots, experiments,
learning_observations, learning_patterns, competitors, benchmark_videos,
research_patterns.

Every generated artifact must be versioned and publication must store
exact artifact versions.
