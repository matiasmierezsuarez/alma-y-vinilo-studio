# Analytics + Learning

Track: views, impressions, CTR, average view duration, average
percentage viewed, watch time, likes, comments, subscribers gained,
traffic sources.

Snapshots: 7d, 28d, 90d.

Learning hierarchy: raw data → observation → pattern → hypothesis →
experiment → result → learning → rule.

Evidence thresholds: 1 signal, 3 preliminary, 5+ strong, 10+ candidate
rule.

Recommendations: REPEAT / EXPAND / TEST / RETIRE.

Learning unit is a Content DNA combination, not merely a video.
