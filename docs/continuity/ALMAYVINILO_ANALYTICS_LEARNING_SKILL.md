# SKILL — ANALYTICS AND LEARNING

## Mission
Turn publication performance into historically correct, attributable, reusable knowledge.

## Historical analytics rule
Analytics must resolve:
published asset -> immutable publication snapshot -> exact historical lineage.

Never analyze an old publication using the current latest Workspace artifact unless the snapshot explicitly references it.

## Learning observation
A learning observation should link performance to the exact creative combination that was published, including relevant decisions such as Content DNA, Scripture, sound profile, vocal choices, visual scenario, thumbnail, title, and packaging.

## Cross-project learning
Future Workspaces may consume aggregated learning, but recommendations must remain explainable and advisory. They must not rewrite historical observations.

## Tests
Required examples:
- analytics resolves historical lineage after Workspace changes;
- learning observation remains stable after regeneration;
- future Workspace recommendation can cite aggregated evidence without mutating source publications.
